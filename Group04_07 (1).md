# Issues

- **Issue 1: Z-ordering bugs during rendering**
  As more entities and visual effects are added, some items may render behind tiles instead of in front.
  *How addressed*: The team will need to maintain a strict render order in `PlayState` or add an explicit Z-index property to `Entity`.
- **Issue 2: EventBus Data Payload Limitation**
  `EventBus` currently only sends `EventType` without a data payload, limiting complex event interactions (e.g., specific damage amounts).
  *How addressed*: TV1 and TV5 will need to coordinate to either implement `std::any` payload support or use alternative state querying mechanisms.
