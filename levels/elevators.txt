# ============================================================
# Elevator routes (moving platforms) — EXTERNAL CONFIG.
#
# Declaring routes here spawns elevators WITHOUT modifying any
# level map file (levels/level1.txt ... stay untouched).
#
# Format (whitespace separated, one route per line):
#   <level file> <startCol> <startRow> <endCol> <endRow> [speed] [pause]
#   - level file   basename of the level (e.g. level2.txt)
#   - start/end    grid column/row of the platform endpoints
#   - speed        platform speed in px/s  (default 60)
#   - pause        seconds to pause at each end (default 1.0)
#
# Axis is inferred from the endpoints:
#   same column (startCol == endCol) -> VERTICAL route
#   same row    (startRow == endRow) -> HORIZONTAL route
#
# Endpoints must be on non-solid tiles and at least one tile apart.
# Lines starting with '#' and blank lines are ignored.
# ============================================================
# MAP SYMBOL NOTE
# You can declare a route directly inside level1.txt, level2.txt, or
# level3.txt by placing '^' at the start and '~' at the end.
#
#   Vertical:   '^' and '~' in the same column.
#   Horizontal: '^' and '~' in the same row.
#
# The markers must replace empty '.' cells, remain inside the map, and must
# not replace solid/climbable tiles. The level theme automatically selects
# the platform palette: Overworld, Underground, Castle, or Underwater.
# Use either map markers OR an entry below for the same elevator, otherwise
# both routes will spawn.
# ============================================================
